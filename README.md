# Impostor

A multiplayer social deduction game where players try to find the impostor among them. The impostor tries to blend in without knowing the secret word.

## Features

- Real-time multiplayer using Socket.IO
- Custom avatars and colors
- Host settings (Time limits, hint modes, word categories)
- Responsive UI

## Tech Stack

- Frontend: React, Vite, Tailwind CSS, Lucide Icons, Framer Motion (motion/react)
- Backend: Express, Socket.IO, TypeScript

## Running locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## Building for production

```bash
# Build client and server
npm run build

# Start production server
npm run start
```
